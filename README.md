# OPG_start — Zoro Browser Prototype

Babylon.js/TypeScript proof-of-concept for a single Zoro character preview before expanding into a cinematic 5v5 RPG.

## Collaboration

We coordinate via [GitHub Issues](../../issues), using `docs/CURSOR_COLLABORATION.md` as the protocol.

**Important:** This repository is public. Do not commit copyrighted game assets, proprietary archives, API keys, personal information, or private logs. Store local source assets outside Git or ignore them.

## First milestone

Research the OPPW4 Mod Loader and compatible extraction workflows. Verify what can be recovered before implementing a Zoro GLB viewer. No claim of original model/animation/VFX accuracy without screenshots and documented evidence.
